     Agent Factory Interactive CLI 설계 문서

     Context

     현재 agent-factory CLI는 af -p project -r role -t task 형태의 플래그 기반 인터페이스로, 사용자가 모든 옵션을 사전에 알아야 합니다.    
     BKIT(비캠프 Vibecoding Kit) 스타일로 대화형 PDCA 체크포인트 기반 UX로 전환하여, af 만 실행하면 온보딩부터 기획→설계→구현→검증까지     
     안내하는 시스템을 만듭니다.

     ---
     아키텍처 개요

     기존 인프라를 최대한 재사용하고, 3개 신규 파일 + 2개 파일 수정으로 구현합니다.

     사용자 → af (인자 없음)
              ↓
        OnboardingWizard (프로젝트명, 설명, 레벨)
              ↓
        PDCAInteractiveChat (REPL + 상태머신)
              ↓
        슬래시 커맨드 → 기존 인프라 연동
          /plan    → ProjectPipeline.prepare()
          /design  → LLM 3옵션 생성 (send_message)
          /do      → ApprovalGate + ProjectPipeline.execute()
          /check   → Evaluator Agent
          /iterate → FSALoop.run_mission()
          /report  → 산출물 요약

     ---
     PDCA 상태 머신

     IDLE → PLAN → PLAN_REVIEW → DESIGN → DESIGN_REVIEW → DO → DO_RUNNING → CHECK → CHECK_REVIEW → ITERATE → COMPLETE
                       ↑ (수정요청)          ↑ (재설계)                                   ↑ (수정)       ↓ (재검증)
                       └── PLAN              └── DESIGN                                   └── CHECK ←────┘

     각 *_REVIEW 단계에서 사용자에게 3가지 선택지 제공:
     - [1] 승인 → 다음 단계로
     - [2] 수정 요청 → 피드백 입력 후 현재 단계 반복
     - [3] 취소 → IDLE로 복귀

     1. core/pdca_state.py (~200줄)

     PDCA 상태 정의 + 상태머신 + JSON 영속화

     class PDCAPhase(Enum):
         IDLE, PLAN, PLAN_REVIEW, DESIGN, DESIGN_REVIEW,
         DO, DO_RUNNING, CHECK, CHECK_REVIEW, ITERATE, COMPLETE

     class ProjectLevel(Enum):
         STARTER = "starter"      # 간단한 앱
         DYNAMIC = "dynamic"      # 풀스택
         ENTERPRISE = "enterprise" # 마이크로서비스

     @dataclass
     class PDCAState:
         project_id: str
         project_name: str
         task_description: str
         level: ProjectLevel
         phase: PDCAPhase
         plan_brief: dict          # /plan 결과
         design_options: list[dict] # /design 3옵션
         selected_design: int       # 선택된 옵션 인덱스
         gap_analysis: dict         # /check 결과
         iterate_count: int
         checkpoint_hashes: dict    # 문서 해시 (무결성)

         def save(workspace) -> str   # .af/pdca_state.json 저장
         def load(workspace) -> Self  # 복원 (세션 재개용)

     class PDCAStateMachine:
         VALID_TRANSITIONS = { ... }
         def transition(target: PDCAPhase) -> None
         def current_phase_label_ko() -> str  # "기획", "설계" 등

     영속화 경로: {workspace}/.af/pdca_state.json

     3. core/pdca_commands.py (~350줄)

     슬래시 커맨드 레지스트리 + 핸들러

     class PDCACommandRegistry:
         def __init__(sm: PDCAStateMachine, chat: PDCAInteractiveChat)

         # 명령어 → 기존 인프라 매핑
         "/plan"    → cmd_plan()    # ProjectPipeline.prepare() 호출
         "/design"  → cmd_design()  # LLM으로 3가지 아키텍처 옵션 생성
         "/do"      → cmd_do()      # ApprovalGate.approve() + execute()
         "/check"   → cmd_check()   # Evaluator agent 실행
         "/iterate" → cmd_iterate() # FSALoop.run_mission()
         "/report"  → cmd_report()  # 산출물 요약 생성
         "/status"  → cmd_status()  # 현재 PDCA 상태 표시
         "/next"    → cmd_next()    # 다음 논리적 단계로 자동 진행
         "/level"   → cmd_level()   # 프로젝트 레벨 변경

         def dispatch(raw_input: str) -> bool  # True면 커맨드 처리됨
