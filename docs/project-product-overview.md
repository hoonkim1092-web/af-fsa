# Project Product Overview

## 목적

`agent-factory`는 복수의 에이전트, 스킬, 훅, 워크플로를 조합해 실제 개발 작업을 계획하고 실행하고 검증하는 팩토리형 시스템을 구축하는 프로젝트다.

## 해결하려는 문제

- 단일 에이전트 중심 흐름으로는 복잡한 개발 작업을 안정적으로 지속 운영하기 어렵다.
- 작업 문서, 실행 규칙, 메모리, 검증 기준이 분산되면 반복 작업 품질이 떨어진다.
- 기능 개발 이후 유지보수와 이슈 수정까지 이어지는 장기 운영 자산이 부족하다.

## 핵심 가치

- 계획과 실행을 분리한 명시적 워크플로
- 멀티 에이전트 기반의 병렬 처리와 역할 분담
- 문서, 정책, 테스트, 메모리의 누적 자산화
- 기존 API와 운영 흐름을 가능한 한 깨지 않는 점진적 개선

## 주요 사용자

- Agent Factory 자체를 개발하거나 유지보수하는 개발자
- 프로젝트별 에이전트 구성을 설계하는 운영자
- 반복 가능한 AI 개발 파이프라인을 구축하려는 실험 사용자

## 성공 조건

- 새 기능이나 수정 작업이 문서 기반 승인 절차를 거쳐 일관되게 수행된다.
- 설계 변경과 운영 규칙이 저장소 문서에 남는다.
- 메모리, 워크플로, 테스트가 단발성 실행이 아니라 축적형 자산으로 동작한다.

## 비목표

- 모든 작업을 무조건 완전 자동으로 처리하는 것
- 특정 모델 또는 특정 제공자에만 종속된 구조를 만드는 것
- 문서만 늘리고 실제 실행 통제를 하지 않는 것

## 문서 운영 원칙

- 제품 목표나 운영 범위가 바뀌면 이 문서를 먼저 갱신한다.
- 작업별 문서는 이 문서의 목적과 범위를 위반할 수 없다.
