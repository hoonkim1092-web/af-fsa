# Registry Schema

`skills/registry.yaml` is the single source of truth.

## Top-Level Keys
- `skills`: map keyed by `skill_id`
- `install_candidates`: map keyed by candidate id

## Skill Entry
```yaml
skills:
  issue_tracker:
    id: issue_tracker
    skill_id: issue_tracker
    name: issue_tracker
    skill_name: issue_tracker
    purpose: Track and update issues
    path: skills/issue_tracker/skill.py
    meta_path: skills/issue_tracker/meta.yaml
    version: "1.0.0"
    status: active
    capabilities: [issue_read, issue_write]
    dependencies: []
    updated_at: "2026-02-23T12:00:00"
    last_test_ok: true
```
