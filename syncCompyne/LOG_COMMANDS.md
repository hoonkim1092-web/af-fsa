# Log Commands

Use these commands to continue context across PCs.

- Save a note:
```bash
python project_log_cli.py save "Today: reviewed agent skills" --type WORK
```

- Read latest session:
```bash
python project_log_cli.py read
```

- Read a specific date:
```bash
python project_log_cli.py read --date 2026-02-19
```
